# گزارش اجرا و تغییرنامه — کیهان صنعت قائم

**تاریخ:** 2026-10-30 / ۸ آبان ۱۴۰۵، Asia/Tehran. رسیدهای ماشینی زمان UTC دارند.  
**وضعیت تحویل:** تغییرات محلی آماده بازبینی/Commit؛ Commit، Push، استقرار و مکاتبه انجام نشده است.

محیط اعتبارسنجی: Windows / PowerShell، Python 3.12.6، پایه مخزن `fab1a5c`. مرورگر قابل اتصال در دسترس نبود. بررسی PDF از کتابخانه‌های نصب‌شده pypdf و PyMuPDF استفاده کرد؛ چیزی نصب نشد.

## اجرای دستور و حفظ کار قبلی

[دستور کار](../CODEX_TASK_FA.md) و تمام ورودی‌های اعلام‌شده خوانده شدند. وضعیت Git ابتدای اجرا پاک بود. هیچ فایل قبلی حذف نشد؛ گزارش اولیه و متن پروپوزال حفظ و با یادداشت تکمیلی به‌روزرسانی شدند. سایر شرکت‌ها و پرونده‌های IPA-001 تا IPA-003 تغییر نکردند. تنها تغییر خارج از پوشه همین شرکت، یک جمله از معیار ارزیابی IPA-004 در `data/problems.json` برای صحیح‌کردن مخرج نرخ هشدار است. قالب، وضعیت و شناسه IPA-004 حفظ شدند. ابزار عمومی خزش و اعتبارسنج موجود پروژه تغییر نکردند.

## پژوهش شبکه و آدرس‌های بررسی‌شده

اجرای فهرست‌برداری از ریشه مخزن:

```text
python tools/public_site_discovery.py --max-pages 32 --delay 2 --out companies/keyhan-sanat-ghaem/research/discovery/2026-10-30
Saved ...public_inventory.json — pages=25, errors=0
```

سقف ۳۲ بود؛ صف لینک‌های مجاز با ۲۵ صفحه تمام شد. [فهرست دقیق تمام URLها و عنوان‌ها](discovery/2026-10-30/public_inventory.json)، [رسید sitemap صفحات](discovery/2026-10-30/page_sitemap_receipt.json) و [جدول لینک‌دار ۲۵ صفحه](PUBLIC_API_INVENTORY.md) قابل بازبینی‌اند. مجموعه دو فهرست مساوی است.

لایه‌های دیده‌شده: صفحه اصلی و معرفی، units و چهار واحد فنی و کنترل کیفیت، محصولات و شش گروه، quality و certificates و qualitypolicies و quality-2، خبرنامه، تاریخچه، پیام سازمان، مأموریت و تماس. این پوشش دامنه همین فهرست عمومی است؛ دارایی‌ها، شبکه‌های اجتماعی، ویدئوها، صفحات خارج از فهرست و دامنه‌های گروه به‌طور جامع بررسی نشدند.

قواعد [robots](https://www.ksgco.com/robots.txt) روی میزبان‌های مجاز بررسی شد؛ منع بخش مدیریت رعایت شد. [نمایه sitemap](https://www.ksgco.com/wp-sitemap.xml) و فقط [شاخه صفحات](https://www.ksgco.com/wp-sitemap-posts-page-1.xml) خوانده شدند. شاخه کاربران خوانده نشد. HTML صفحات عمومی با GET و فاصله حداقل ۲ ثانیه برای metadata، canonical، فرم‌ها، JSON-LD و لینک‌های PDF/API بازبینی شد؛ محتوای کامل ذخیره نشده است.

PDF عمومی دقیقاً از لینک تصویری صفحه محصول کشف شد. لینک اصلی `http://www.ksgco.com/wp-content/uploads/2018/03/GHAEM-2015.pdf` بود؛ فقط scheme همان منبع به HTTPS ارتقا یافت. پاسخ مستقیم 200 با امضای PDF ثبت شد. تحلیل با pypdf و پیش‌نمایش محلی با PyMuPDF: **۲۸۵ صفحه، ۲۸۳ صفحه دارای متن استخراج‌پذیر، 5,874,441 بایت**. ساختار متن کل فایل و چند نمونه بررسی شد؛ تمام ردیف‌ها دستی تأیید نشده‌اند. hash در [رسید کاتالوگ](discovery/2026-10-30/catalog_review.json) است. تصویر نمونه برای مشاهده در پوشه موقت سیستم بود؛ PDF و تصاویر کامل در Git نیستند.

## APIهای کشف‌شده و مرز استفاده

[فهرست API](PUBLIC_API_INVENTORY.md) شامل ریشه اعلام‌شده `https://www.ksgco.com/wp-json/` و alternateهای JSON همان ۲۵ صفحه است. ریشه و پاسخ هر صفحه فقط با `_fields` و بدون حساب دریافت شدند؛ ۲۵ پاسخ صفحه موفق و publish بودند. نمونه pages/51 برای خانه، pages/160 برای ماشین‌کاری و pages/162 برای آزمایشگاه از HTML استخراج شده‌اند؛ شناسه یا endpoint حدس زده نشد. [رسید پاسخ‌ها](discovery/2026-10-30/advertised_page_api_receipts.json) فقط id، تاریخ‌های GMT، لینک، وضعیت و نوع را دارد.

oEmbed، RSS، XML-RPC/RSD، پیکربندی admin-ajax و namespace افزونه فرم فقط مشاهده شدند؛ عملیات مربوطه فراخوانی نشد. هیچ کاربر، نویسنده، دیدگاه، کوکی، توکن، حساب، فرم یا داده تولید دریافت/ارسال نشد. API عملیاتی کارخانه در منابع مجاز بررسی‌شده معرفی و تأیید نشد (`NOT_PUBLICLY_VERIFIABLE`). نام namespace یا کد وضعیت 200 مجوز دسترسی به هر مسیر دیگری تلقی نشد.

## محدودیت‌ها و خطاها؛ مستقل از عیب سایت

| مورد | آنچه واقعاً رخ داد | اثر بر نتیجه |
|---|---|---|
| robots در ابزار وب | ابزار وب نتوانست باز کند؛ GET مستقیم 200 و متن قواعد دریافت شد | خزش فقط پس از روشن‌شدن قواعد انجام شد |
| products در ابزار وب | timeout یک مشاهده؛ HTML مستقیم موفق بود | «صفحه خراب» ثبت نشد |
| PDF در ابزار وب | بازکردن HTTP/HTTPS ممکن نبود؛ دریافت مستقیم موفق | لینک PDF سالم در این دریافت؛ محدودیت ابزار با خرابی فایل مخلوط نشد |
| مرورگر واقعی | اتصال Browser پاسخ No browser is available و فهرست مرورگرها خالی بود | رندر JS، موبایل بصری، کنسول و شبکه مرورگر تأیید نشد؛ ابزار دیگری برای دورزدن به‌کار نرفت |
| مقاله بیرونی | پیوند عیب‌یابی خبرنامه در ghaemg.com با ابزار وب 404 داد | متن آن مبنای نتیجه صنعتی نشد؛ خطای مبدأ مستقلاً تأیید نشده |
| داده و گواهینامه | داده عملیاتی، دامنه/اعتبار امروز گواهی و همکاری شرکت تأیید نشد | UNKNOWN و شرط توقف صریح ثبت شد |

هیچ 401/403/429 در درخواست‌های مستقیم ثبت‌شده مشاهده نشد؛ هیچ محدودیت دسترسی دور زده نشد. هیچ تست آسیب‌پذیری، پورت‌اسکن، مسیر پنهان، ورود یا تغییر ماشین انجام نشد. نسخه افزونه‌ها در HTML به‌عنوان اثبات آسیب‌پذیری تحلیل نشد. وضعیت عمومی سایت در تاریخ دیگر ممکن است متفاوت باشد.

## آزمون‌ها و حدود آن‌ها

هر دو فرمان موجود CI از ریشه اجرا شدند:

```text
python tools/validate_atlas.py
PASS: 4 case files validated; 5 pages/link checks passed.

python pilot/synthetic_sensor_demo.py --check
PASS: synthetic demo self-check; no outputs written.
```

اعتبارسنج عمومی موجود فقط پنج صفحه ریشه را پوشش می‌دهد؛ این خروجی به‌تنهایی آزمون صفحه شرکت نیست. کنترل تکمیلی پرونده، لینک‌های HTML/Markdown، شناسه‌های دفتر و والدهای شواهد، تطبیق sitemap، ثابت‌ماندن سایر پرونده‌ها و دریافت HTTP محلی صفحه شرکت/فهرست/IPA-004/مسیر تاریخی را نیز بررسی کرد. نتیجه: **PASS، تعداد ۳۱ کنترل و ۸ مسیر HTTP**؛ جزئیات در [verification_results.json](verification_results.json) ثبت شد. `git diff --check` نیز با کد خروج صفر تمام شد. هشدار Git درباره تبدیل LF/CRLF، خطای محتوا یا آزمون نبود.

کنترل تکمیلی با اسکریپت محلی `research/crawl_runs/verify_company.py` اجرا شد؛ این پوشه طبق `.gitignore` پیشین خارج از انتشار است. نتیجه مختصر و قابل بازبینی در JSON بالا می‌ماند. در اجرای نخست، مسیر ریشه اسکریپت موقت اصلاح شد و سپس چک پیوند فایل نتیجه پس از ایجاد خود فایل تکرار شد؛ اجرای نهایی همه کنترل‌ها را گذراند. هیچ خطای باقی‌مانده در خروجی نهایی ثبت نشده است.

کنترل محلی HTTP و ساختار داده جایگزین رندر مرورگر و آزمون دیداری موبایل نیست. طراحی صفحه دارای RTL، viewport و breakpoint موجود برای نمایش تک‌ستونی است؛ خوانایی بصری موبایل در این محیط تأیید نشده است. آزمون دمو داده مصنوعی دارد و هیچ شاهد عملکرد صنعتی برای کیهان صنعت قائم تولید نمی‌کند.
