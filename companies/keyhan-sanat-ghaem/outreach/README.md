# تماس با شرکت — تفکیک عمومی/خصوصی

اینجا فقط راهنمای عمومی مکاتبه نگهداری می‌شود. **هیچ نامه ارسالی، پاسخ خصوصی، فایل پیوست محرمانه، اطلاعات تماس شخصی، یا داده‌ای که شرکت خصوصی تلقی می‌کند در مخزن عمومی GitHub قرار ندهید.**

- تماس رسمی منتشرشده: https://www.ksgco.com/contactus/
- ابتدا صفحه عمومی `../index.html` را منتشر و در مرورگر بررسی کنید.
- درخواست یک گفت‌وگوی کوتاه با واحد فنی/کیفیت؛ بدون ادعای عیب و بدون وعده صرفه‌جویی.
- پیش از دسترسی به داده داخلی، اجازه صریح، توافق محرمانگی و دامنه کار مشخص لازم است.
- متن‌ها و پیگیری‌های واقعی در پوشه محلی `outreach/private/` باشند که توسط `.gitignore` کنار گذاشته می‌شود.
