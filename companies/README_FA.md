# ساختار پرونده هر شرکت

برای هر شرکت یک پوشه `companies/<company-slug>/` بسازید. نام کوتاه و ASCII باشد.

- `index.html` صفحه عمومی به زبان فارسی
- `company.json` دامنه رسمی، منابع اولیه، محدودیت‌ها
- `research/` منابع، دفتر شواهد، فرضیات قابل آزمون
- `proposals/` پیشنهادهای مهندسی؛ تمایز خط مبنا و AI
- `outreach/` فقط الگوهای عمومی؛ مکاتبات واقعی در `outreach/private/` خارج از Git
- `CODEX_TASK_FA.md` دستورکار پژوهش اختصاصی

هیچ مسئله یا نتیجه داخلی را از روی اطلاعات عمومی اثبات‌شده تلقی نکنید.
